# Production deployment

Production runs on a VPS with [Coolify](https://coolify.io). Coolify builds the repository from `docker-compose.prod.yml` at the root, and its Traefik proxy terminates HTTPS with Let's Encrypt certificates.

`docker-compose.yml` is the local development stack. Never deploy it: it publishes Postgres and Mailpit ports.

## Services

| Service | Image | Exposed |
|---|---|---|
| `api` | built from `Dockerfile` | port `8080` on the Coolify network, behind Traefik. No published port. |
| `db` | `postgres:18` | internal only. Data in the `db` volume. |

`api` serves the JSON API under `/api/v1`, the admin under `/admin`, and `/health`. One domain is enough.

The `api` container runs `/app/migrate`, then `/app/api`. A failed migration stops the container before the API starts. Migrations already applied are skipped, so a restart is safe. `api` starts only when `db` is healthy, and its own health check calls `/health`.

## Coolify settings

| Setting | Value |
|---|---|
| Build pack | Docker Compose |
| Repository, branch | `kejlerj/league-s`, `main` |
| Base directory | `/` |
| Docker Compose location | `/docker-compose.prod.yml` |
| Domain of `api` | `https://league.jejedev.fr:8080` |

## Environment variables

Set them in Coolify. Nothing secret goes into git.

| Variable | Required | Value |
|---|---|---|
| `SERVICE_USER_POSTGRES` | generated by Coolify | Postgres user, also used by the app |
| `SERVICE_PASSWORD_POSTGRES` | generated by Coolify | Postgres password, also used by the app |
| `DB_DATABASE` | no, default `league` | Database name |
| `CORS_ORIGINS` | yes | `https://league.jejedev.fr` |
| `ADMIN_URL` | yes | `https://league.jejedev.fr/admin`, used in the links of emails |
| `SUPERADMIN_EMAIL` | yes | The account that becomes superadmin |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `MAIL_FROM` | no | Without `SMTP_HOST`, invitations and password resets are not sent. `SMTP_PORT` defaults to `587`. |
| `SENTRY_DSN` | no | API errors to Sentry |
| `VITE_SENTRY_DSN` | no | Admin errors to Sentry, read at build time |
| `LOG_LEVEL` | no, default `info` | `debug`, `info`, `warn` or `error` |
| `CLEANUP_INTERVAL` | no, default `1h` | How often expired sessions, resets and invitations are deleted |

`docker-compose.prod.yml` sets the rest: `APP_ENV=production`, `PORT=8080`, `LOG_FORMAT=json`, `COOKIE_SECURE=true`, `DB_HOST=db`. Coolify's `SOURCE_COMMIT` becomes the admin's Sentry release.

## Check the file locally

```bash
export SERVICE_USER_POSTGRES=league SERVICE_PASSWORD_POSTGRES=local CORS_ORIGINS=https://league.example.com SUPERADMIN_EMAIL=admin@example.com ADMIN_URL=https://league.example.com/admin
docker compose -p league-s-prod-check -f docker-compose.prod.yml up -d --build --wait
docker compose -p league-s-prod-check -f docker-compose.prod.yml exec -T api wget -qO- http://127.0.0.1:8080/health
docker compose -p league-s-prod-check -f docker-compose.prod.yml down -v
```
